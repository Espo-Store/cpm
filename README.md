## 📱 TUTORIAL TERMUX

Jalankan perintah di bawah **satu per satu**.

### 1. Update Termux
```bash
pkg update && pkg upgrade
```

### 2. Install Python & Git
```bash
pkg install python git
```

### 3. Clone Repository
```bash
git clone https://github.com/Espo-Store/cpm.git
```

### 4. Masuk ke Folder
```bash
cd cpm
```

### 5. Install Library
```bash
pip install requests
```


### g. Jalankan Tools
```bash
python main.py
```
